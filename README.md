# tomfit.app

Static website for TOMfit – a simple health & fitness app for adults 50+.
Hosted on Cloudflare Pages (no build step: output directory is the repo root).

## Editing
Pages are generated by `_build/build.py` (run `python3 _build/build.py` from the repo root).
Edit text there, rebuild, then commit and push – Cloudflare publishes automatically.
